# GitHub轻量版 工作台与PDF通用保存

## 上传到现有GitHub仓库

1. 解压ZIP，将里面所有文件以及 images 文件夹上传到原仓库根目录，与旧 index.html 放在同一级。不要只上传ZIP或index.html，也不要在外面再包一层文件夹。
2. 选择直接提交到原来的 main 发布分支，点击 Commit changes。等待 Actions 中的 pages build and deployment 变为绿色，再刷新原公开链接。
3. 本包共35个文件，其中26个图片文件放在 images 文件夹。可在GitHub的 Add file → Upload files 中拖入根目录文件和 images 文件夹，一次上传。
4. 保持原仓库名称和原网址，即可继续使用同一浏览器保存的学习进度。不要为了更新清理浏览器数据。换网址或设备前请导出备份。

## 小体积加载

网页先加载文字词库和程序。红宝书按页栏保存为26个压缩图片文件，仅查看相应词条或打印时加载。目录齐全才能显示图片。
PDF由内置程序直接生成，无需额外PDF库、云端接口或外部字体。首次生成PDF不请求第三方服务。

## 下载PDF

点击“打印今日词表”，选择完整释义版或遮义自测版，再点击“下载PDF词表”。
生成后会出现“保存PDF文件”和“打开PDF预览”。若浏览器不自动下载，可手动点保存；或打开预览后，通过预览页自己的保存/分享菜单保存。
支持文件分享的设备还会出现“系统分享／保存”。取消分享不会删除PDF，也不会修改背诵进度。系统阻止的下载无法由网页强制绕过。
PDF以页面图像保存，适合查看和打印，PDF中的文字不支持搜索复制。

## 浏览器与验证范围

核心生成、文件下载、PDF预览和分享分支均有本地自动化测试。模拟手机或平板尺寸不等于这些设备实机验证，未声称已测试所有手机、Safari或夸克版本。
本包减少首次下载量，但不能保证GitHub Pages在所有国内网络下都能连通。
