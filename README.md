# 工作台轻量上线版

这是多文件部署版，网页与词库先加载，红宝书图片在揭晓释义或打印时加载，PDF直接由页面内置程序生成，不需要下载额外组件。
文件夹内的 images 必须一起上传，不能只上传 index.html，也不要把整个 ZIP 当作网页文件上传到 GitHub。

## Netlify

打开现有项目的 Deploys，将整个ZIP或解压后的“轻量上线版”文件夹拖到部署区，完成后刷新原来的网址。保留原项目和网址可沿用当前浏览器中的学习记录。

## Cloudflare Pages

使用静态资产直接上传，将整个ZIP或解压后的文件夹上传。不要选择需要后端代码的 Worker 模板。若连接GitHub做自动部署，请提交完整目录，包括 images，构建命令留空，发布目录为放有 index.html 的目录。

## GitHub Pages

需要把全部目录和文件提交到原仓库的发布目录。图片数量较多，不适合用网页逐张上传，建议使用 GitHub Desktop 同步整个目录。只替换HTML无法获得此版本的加载优化。

## 使用与进度

核心词库、频次、六个板块、循环复习、进度存储键保持一致。备份修复、打印预览、PDF下载保留。离线使用请继续用原来的单HTML本地版。
更换网址或域名时，浏览器不会自动搬迁进度，请先在旧网站导出备份，再在新网站导入。图片按需加载也意味着第一次查看未缓存的图片释义需要网络。

## 速度边界

本包减小了首次打开需要下载的内容，无法保证某个海外域名在所有国内网络下都可连接。请先让朋友在实际网络中测试，不必为了试用先购买付费套餐。
